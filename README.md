# Homebrew tap for GridPin

[GridPin](https://gridpin.dev) is an offline geocoder: a country in a file, addresses to coordinates without a network.

```console
$ brew install gridpin/gridpin/gridpin
$ gridpin --version
```

The formula installs the prebuilt program of a [GitHub release](https://github.com/gridpin/gridpin/releases)
(macOS on Apple silicon, Linux x86_64) and checks its SHA-256. Country files are downloaded separately:
see [the documentation](https://gridpin.dev/docs).

The formula is generated from the release; issues go to [gridpin/gridpin](https://github.com/gridpin/gridpin/issues).
